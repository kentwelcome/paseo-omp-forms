# Agent teams

[All guidelines](../README.md)

OMP Forms uses the shared project guidelines without an agent team. No team runbooks, host bindings, or delegation entry are installed. Tracker setup is independent of team selection.

Treat Agent Dev Team or Spacedock as separate opt-ins. If the maintainer requests either, consult the team adoption guide at the [recorded template revision](../AGENTS.md#template-source), verify the selected host and tracker prerequisites, and adopt only the selected team's files. Preparing a team does not authorize installation, dispatch, tracker writes, or delivery. Use the [review](review.md) and [delivery](development.md#delivery-and-handoff) rules regardless of team choice.
